A tiny program for the [Rename the Planet](https://make.fun/c/u-motasimfuad-rename-the-planet-094b0369) competition on make.fun. It writes one funny new name for a planet in our solar system, plus the why, in a single line under 200 characters, to `/output/entry.txt`.

## Run

```sh
node main.ts
```

## Entry

Mars is now "The Red Flag" — dry, cold, toxic dust, and yet everyone keeps swiping right on it.
